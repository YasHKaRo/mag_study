Проверочные вопросы

Что такое TCP/IP?
а) Программа для просмотра интернет-страниц
б) Операционная система для серверов
в) Сетевая модель передачи данных, описывающая способ передачи информации от источника к получателю через несколько уровней — ПРАВИЛЬНО
г) Язык программирования для создания связей между устройствами
Информация: https://www.geeksforgeeks.org/computer-networks/tcp-ip-model/

Чем IP-адрес принципиально отличается от MAC-адреса?
а) Ничем, они идентичные 
б) IP-адрес — это логический, назначаемый адрес для сетевой маршрутизации, а MAC-адрес — это физический, "прошитый" в оборудовании адрес — ПРАВИЛЬНО
в) MAC-адрес используется для идентификации в Интернете, а IP-адрес — только в локальной сети
г) IP-адрес всегда короче MAC-адреса
Информация: https://www.geeksforgeeks.org/computer-networks/difference-between-mac-address-and-ip-address/

Команда `ping 8.8.8.8` возвращает ошибку `Network is unreachable`. В чём наиболее вероятная причина?
а) На хосте 8.8.8.8 запрещены ICMP-ответы
б) На вашей машине не запущен веб-браузер
в) На вашей машине отсутствует маршрут до указанного адреса — ПРАВИЛЬНО
г) DNS-сервер не отвечает
Информация (а чё нет то?): https://www.reddit.com/r/Ubuntu/comments/1d80xmi/ping_8888_gets_network_is_unreachable_but_ping/?tl=ru

Что означает строка `LISTEN 0 1 127.0.0.1:3000 0.0.0.0:*` в выводе команды `ss -tnlp`?

а) Процесс слушает входящие подключения на порту 3000, но только с самой этой же машины (localhost) — ПРАВИЛЬНО
б) Установлено активное соединение с портом 3000 на удалённом хосте
в) Порт 3000 закрыт и ничем не используется
г) Это маршрут для трафика, идущего на порт 3000
Информация: https://habr.com/ru/articles/503648/

С помощью какой утилиты можно вручную отправить HTTP-запрос, не используя браузер или специализированные библиотеки?
а) Только с помощью `ping`
б) С помощью `nslookup`
в) С помощью `arp`
г) С помощью `telnet` или `curl` — ПРАВИЛЬНО
Информация: https://www.geeksforgeeks.org/linux-unix/curl-command-in-linux-with-examples/
