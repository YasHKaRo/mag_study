Задание 4. Генерация псевдослучайных чисел с LFSR и анализ распределения
Условие:
Используя LFSR с многочленом ( x^6 + x + 1 ) (taps = [6, 1]) и начальным состоянием
[1,0,0,0,0,0], сгенерируйте последовательность длиной 63 бита. Подсчитайте количество
единиц и нулей и постройте гистограмму распределения (можно с помощью matplotlib).
Подсказка:
• Код генерации аналогичен Заданию 4.
• Для построения гистограммы используйте:

counts = [seq.count(0), seq.count(1)]
